# 🌦️ Weather App Pro

A clean and professional weather application built using HTML, CSS, and JavaScript.

## 🚀 Features

- Search weather by city name
- Live temperature data
- Humidity details
- Wind speed
- Clean white professional UI
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- OpenWeather API
